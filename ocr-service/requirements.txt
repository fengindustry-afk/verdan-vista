# Default backend (PaddleOCR). CPU wheels; first run downloads the models.
# Held at 2.x on purpose: backends/paddle_backend.py uses the 2.x API, which
# 3.x removed. PaddleOCR(use_angle_cls=..., show_log=...) is gone (3.x renamed
# it use_textline_orientation and dropped show_log), .ocr(arr, cls=True) is
# replaced by predict(), and the result is no longer [box, (text, conf)] pairs
# but an object exposing rec_texts / rec_scores / dt_polys. Lifting the ceiling
# without porting that file breaks the service at construction and again at the
# result unpack. See docs/version3.x/pipeline_usage/OCR.html.
